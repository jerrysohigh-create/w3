08.3 / W3 SCOPE

生态不是 Logo 墙。
它是一份证据登记册。

生态关系不是视觉资产，而是可追溯的公开记录。W3 只收录能够回到双方公告、公开代码、链上交互、共同活动或独立报道的生态信号。

01 / EVIDENCE GATE

六类来源关系

先标记谁发布，再判断它能证明什么。

  1. 01
    DUAL-SOURCE RELEASE双方各自正式公告
    必须同时保留双方原始 URL；只有转发不算双源。
  2. 02
    MAGNE ORIGINALMAGNE 单方发布
    可作为 Company Release，不包装成第三方确认。
  3. 03
    PARTNER ORIGINAL合作方单方发布
    可作为 Partner Release，仍需检查 MAGNE 是否回应或转发。
  4. 04
    PUBLIC CODE / ON-CHAIN公开代码与链上交互
    Repository、SDK、合约、交易与可复核统计口径。
  5. 05
    AMA / EVENT共同活动记录
    证明共同参与，不自动证明产品集成或持续合作。
  6. 06
    INDEPENDENT COVERAGE独立报道
    媒体来源与 Company Release 分开标记。
02 / PUBLIC STATUS

三档公开状态

状态描述证据成熟度，不代表投资、上线或价值承诺。

VERIFIED DUAL-SOURCE
双方各自原始公告均已找到，或存在可执行、可检查的公开集成。
HISTORICAL SINGLE-SOURCE
只有 MAGNE 或合作方一侧的历史发布，公开展示发布方但不称双方确认。
SOURCE CONFLICT
名称、日期或链接冲突；修正前不进入正式生态名录。

RESTRICTED / NDA、未公开协议与交易所沟通只进入受控 DD，不在 NEWSROOM 公开。
