08.3 / W3 SCOPE

Ecology is not a logo wall.
It is a register of evidence.

Ecological relationships are not visual assets but traceable public records. W3 only includes ecological signals that can be traced back to announcements, public codes, on-chain interactions, joint activities or independent reports from both parties.

01 / EVIDENCE GATE

Six types of source relationships

Flag who posted it first, then judge what it proves.

  1. 01
    DUAL-SOURCE RELEASEOfficial announcements from both parties
    must retain the original URLs of both parties; only forwarding does not count as dual origin.
  2. 02
    MAGNE ORIGINALMAGNE Unilateral Release
    is available as a Company Release and is not packaged for third-party confirmation.
  3. 03
    PARTNER ORIGINALUnilateral release by the partner
    can be used as Partner Release, but it still needs to be checked whether MAGNE responds or forwards.
  4. 04
    PUBLIC CODE / ON-CHAINPublic code and on-chain interaction
    Repository, SDK, contracts, transactions and reviewable statistics.
  5. 05
    AMA / EVENTCommon activity records
    Demonstrates joint participation and does not automatically demonstrate product integration or ongoing collaboration.
  6. 06
    INDEPENDENT COVERAGEIndependent reporting
    Media sources are marked separately from Company Release.
02 / PUBLIC STATUS

Third level public status

Status describes the maturity of evidence and does not represent investment, go-live, or a commitment to value.

VERIFIED DUAL-SOURCE
The original announcements from both parties have been found or there is an executable and inspectable public integration.
HISTORICAL SINGLE-SOURCE
Historical releases only from one side of MAGNE or the partner, publicly displayed by the release party but not confirmed by both parties.
SOURCE CONFLICT
Name, date or link conflict; will not be entered into the official ecological directory until corrected.

RESTRICTED / NDA, undisclosed protocol and exchange communication only enter controlled DD and are not disclosed in NEWSROOM.
