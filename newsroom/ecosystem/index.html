01 / UNIFIED TIMELINE

按时间合并，
再反查对方动作。

历史索引与公开补录现在合并为一条倒序时间线。每条记录同时保留数据层、首发账号、确认方式与原始 X status；“双方确认”不再只限双方各发一篇。“ONE X URL”只表示目前保存了一条原帖，不代表合作事实上只有单方。

BILATERAL RULE / 以下三种都计为双方确认：双方各自发布；一方发布且对方官方账号明确回复、引用或确认；一方发布且对方官方账号转发。点赞、同场活动、Logo 引用、第三方转发和独立报道均不计。 OFFICIAL REFERENCE POLICY ↗

SOURCE CONTROL / 第三方镜像只用于发现和回收 status ID，不作为 W3 页面来源。双方官方互动已经确认的记录归入蓝色 BILATERAL；尚未恢复的 status ID 会在行内继续透明标注。关系本身仍待确认的条目才列入 X ID PENDING。

02 / CHRONOLOGICAL LEDGER

首发、确认、来源，
放在同一行。

反查结果会把双方官方确认的记录升级为 DUAL POST、OFFICIAL RESPONSE、OFFICIAL REPOST 或 OFFICIAL CONFIRMATION。部分原始 status ID 尚未恢复时，记录仍保留蓝色双边状态并明确披露缺口；关系本身尚未确认的才保留在 PENDING。
