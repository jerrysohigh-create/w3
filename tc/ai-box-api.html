MAGNE.AI BOX 開發者API指南

開發者預覽版v0.1 · 內容更新：2026-11-07

本指南供已取得MAGNE.AI BOX開發預覽設備的應用開發者使用，涵蓋本地推理、知識庫及模型管理。ROC是目前交付資料中的軟體服務與工具命名；本指南不聲明MAG1接口相容。

適用於已配置本文接口及HTTPS管理口的預覽設備。具體支援韌體以交付記錄及GET /v1/version為準。以下接口沿用OpenAI風格的請求結構，不代表完整API或所有Agent工具相容。

連接與前置準備

準備已交付設備、可傳輸資料的USB線、ADB，以及交付方提供的管理信任憑證、管理員帳戶和應用令牌。本文不包含設備初始化、管理員復原或維護權限取得流程。

以下命令採用POSIX shell語法；Windows可在已配置工具的WSL或Git Bash執行。

SH
adb devices -l
adb -s DEVICE_SERIAL forward --no-rebind tcp:8080 tcp:8080
adb -s DEVICE_SERIAL forward --no-rebind tcp:18081 tcp:18081

DEVICE_SERIAL替換為實際設備序列號。若端口被佔用，先檢查adb forward --list，不要覆蓋其他設備的轉發。

業務Base URL為http://127.0.0.1:8080/v1；管理Base URL為https://127.0.0.1:18081/admin/api。業務HTTP僅用於本機回環及受控USB轉發。Wi-Fi連線不會自動開放LAN業務接口。其他主機接入需由部署方提供受控通道。

不要將ADB或上述接口直接暴露至公網。網站本身不需要接收您的設備密碼或令牌。不要使用-k略過憑證驗證。舊HTTP管理韌體請使用交付方提供的對應指南。

模型查詢與第一個請求

由本機安全環境提供ROC_API_TOKEN；它是應用令牌，不是管理員session。避免把真實憑據寫入網站程式、公開範例或日誌。

SH
BASE=http://127.0.0.1:8080/v1
curl -sS "$BASE/version" -H "Authorization: Bearer $ROC_API_TOKEN"
curl -sS "$BASE/models" -H "Authorization: Bearer $ROC_API_TOKEN"

從清單選擇公開模型ID。以下使用交付資料中的local/qwen35-35b示例；這是服務別名，不能單獨用來判定完整模型版本或量化。

SH
curl -sS "$BASE/models/local%2Fqwen35-35b/health" \
  -H "Authorization: Bearer $ROC_API_TOKEN"

curl -sS "$BASE/chat/completions" \
  -H "Authorization: Bearer $ROC_API_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"model":"local/qwen35-35b","messages":[{"role":"user","content":"What is 19 + 23? Reply only the integer."}],"temperature":0,"max_tokens":32,"stream":false}'

模型model_ready=true後再送出推理請求。未載入模型需由管理員先執行load/switch。成功答案位於choices[0].message.content；多輪對話隨請求攜帶完整所需messages歷史。

對話流式模式設stream:true並使用curl -N讀取SSE，收到[DONE]才視為正常結束。連線中斷不等同成功。

Embedding與Rerank

SH
curl -sS "$BASE/embeddings" \
  -H "Authorization: Bearer $ROC_API_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"model":"npu/embedding","input":"Document text"}'

curl -sS "$BASE/rerank" \
  -H "Authorization: Bearer $ROC_API_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"query":"network","documents":["network setup","weather"],"top_n":2}'

交付配置的Embedding返回1024維向量，位置為data[0].embedding；Rerank的results包含文件索引與相關性分數。npu/embedding及npu/rerank不使用/models/{id}/health，狀態由管理接口GET /admin/api/models查詢。開機未就緒時可能返回503。

文件與知識庫

步驟接口請求及結果
上傳POST /v1/filesmultipart：purpose=assistants及file；保存file_id
建庫POST /v1/vector_storesJSON：{"name":"customer-docs"}；保存返回id
掛接POST /v1/vector_stores/{id}/filesJSON：{"file_id":"FILE_ID"}
等待入庫GET /v1/vector_stores/{id}/files/{file_id}等待status=completed；failed/cancelled需處理
檢索POST /v1/vector_stores/{id}/searchJSON：{"query":"查詢詞"}
問答POST /v1/responses使用下列file_search請求

將以下內容保存為rag.json，替換模型與知識庫ID：

JSON
{
  "model": "local/qwen35-35b",
  "instructions": "Answer briefly and cite the source.",
  "input": [{"role":"user","content":"What is the verification keyword?"}],
  "tools": [{"type":"file_search","vector_store_ids":["YOUR_VECTOR_STORE_ID"]}],
  "max_output_tokens": 128,
  "stream": true
}
SH
curl -sS -N "$BASE/responses" \
  -H "Authorization: Bearer $ROC_API_TOKEN" \
  -H 'Content-Type: application/json' --data-binary @rag.json

只有收到response.completed才記為完整成功。response.failed讀取response.last_error；response.incomplete及終止事件前斷流均不算完整成功。保留X-Request-ID，不要在部分輸出後無條件重送。

答案應展示返回的文件引用。OCR在文件入庫路徑中處理；格式、大小、頁數和複雜版面支援範圍以交付配置和實測為準。此指南不承諾所有文件均能正確解析。

刪除知識庫用DELETE /v1/vector_stores/{id}，刪除文件用DELETE /v1/files/{file_id}；執行前確認歸屬和用途。

管理員認證與應用令牌

管理員登入：POST /admin/api/login，JSON包含username與password，返回session。HTTPS請求需信任交付憑證，管理請求使用Authorization: Bearer <session>。登出用POST /admin/api/logout。

業務請求使用獨立應用令牌。由管理員透過交付的管理介面或核准工具簽發、輪換和撤銷；能力範圍為inference、embeddings、rerank、rag，依實際需要授權。一般應用令牌明文僅在簽發/輪換時返回。輪換使舊令牌失效；遺失令牌應重新簽發或輪換。設備交付及維護憑據不屬於應用令牌流程。

模型載入與切換

在已安全取得管理session後，由本機環境提供ADMIN_SESSION。下列TARGET_ID與COPY_REVISION須用管理清單的當次值替換；管理ID與業務ID可能不同。

SH
ADMIN=https://127.0.0.1:18081/admin/api
curl -sS --cacert provider-admin-trust.pem "$ADMIN/models" \
  -H "Authorization: Bearer $ADMIN_SESSION"

curl -sS -i --cacert provider-admin-trust.pem "$ADMIN/models/switch" \
  -H "Authorization: Bearer $ADMIN_SESSION" \
  -H 'Content-Type: application/json' \
  -d '{"target":{"id":"TARGET_ID","revision":"COPY_REVISION"}}'

curl -sS --cacert provider-admin-trust.pem "$ADMIN/models/operations/OPERATION_ID" \
  -H "Authorization: Bearer $ADMIN_SESSION"

已有模型駐留使用switch，沒有模型駐留使用load。HTTP 202僅表示受理，保存operation_id並輪詢原操作至succeeded/failed/cancelled。切換期間暫停業務；同時確認操作成功、目標模型就緒及實際短問答成功後再恢復。冷載入可能需要數分鐘。

開機預設策略使用GET /admin/api/models/policy讀取；PUT為整份替換且帶version鎖。必須保留其他欄位，409時重新讀取。保存策略不代表當前模型已切換。

健康與排障

管理接口提供GET /admin/api/status、/health、/system/health、/device/thermal、/device/thermal/history及/audit/export。均需管理員session及HTTPS憑證驗證。

HTTP處理
400核對請求欄位、模型及參數
401/403檢查應用令牌、管理session或scope；按需重新登入或輪換
404檢查路由、模型ID編碼及是否支援該接口
429降低並發或等待登入鎖定解除
503查模型就緒狀態，保留錯誤碼與請求ID

報障提供時間與時區、版本、模型ID、請求類型、HTTP狀態及X-Request-ID；分享日誌前移除秘密和業務敏感內容。

USB重連後重新建立轉發。使用結束移除：

SH
adb -s DEVICE_SERIAL forward --remove tcp:18081
adb -s DEVICE_SERIAL forward --remove tcp:8080
