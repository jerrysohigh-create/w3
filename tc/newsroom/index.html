08.3 / W3 SCOPE

生態不是 Logo 牆。
它是一份證據登記冊。

生態關係不是視覺資產，而是可追溯的公開記錄。 W3 只收錄能夠回到雙方公告、公開程式碼、鏈上互動、共同活動或獨立報道的生態訊號。

01 / EVIDENCE GATE

六類來源關係

先標記誰發布，再判斷它能證明什麼。

  1. 01
    DUAL-SOURCE RELEASE雙方各自正式公告
    必須同時保留雙方原始 URL；只有轉送不算雙重來源。
  2. 02
    MAGNE ORIGINALMAGNE 單方發布
    可作為 Company Release，不包裝成第三方確認。
  3. 03
    PARTNER ORIGINAL合作方單方發布
    可作為 Partner Release，仍需檢查 MAGNE 是否回應或轉送。
  4. 04
    PUBLIC CODE / ON-CHAIN公開程式碼與鏈上互動
    Repository、SDK、合約、交易與可複核統計口徑。
  5. 05
    AMA / EVENT共同活動記錄
    證明共同參與，不自動證明產品整合或持續合作。
  6. 06
    INDEPENDENT COVERAGE獨立報道
    媒體來源與 Company Release 分開標記。
02 / PUBLIC STATUS

三檔公開狀態

狀態描述證據成熟度，不代表投資、上線或價值承諾。

VERIFIED DUAL-SOURCE
雙方各自原始公告均已找到，或存在可執行、可檢查的公開整合。
HISTORICAL SINGLE-SOURCE
只有 MAGNE 或合作方一側的歷史發布，公開展示發布方但不稱雙方確認。
SOURCE CONFLICT
名稱、日期或連結衝突；修正前不進入正式生態名錄。

RESTRICTED / NDA、未公開協議與交易所溝通只進入受控 DD，不在 NEWSROOM 上公開。
