// 02 · WHY W3

W3 是 MAGNE.AI 在 Phone Gen 1 之外的一層新基礎設施。

它給 AI Agent 身份、策略、受控支付、收據 — 跟 Phone 一樣，在矽上發生，但這次不是手機，是整個 Agent 經濟的執行層。

// 不是

W3 不是 Agent。

它不替你做決定，也不替你跑服務。它是一條 受控的、可驗證的 路 — Agent 經過這條路，產生可被引用、可被質押、可被審計的證據。

// 為何需要

Agent 之間需要契約。

當 Agent A 替 Agent B 買了 0.42 USDC 的推論，誰簽、誰付、誰負責 — 沒有 W3，這些問題在鏈上沒有答案。

// 現在

測試網 + 沙盒支付。

W3 已在 M Hash L2 測試網上線（Chain ID 20250827），支付走沙盒協議 — 每筆交易都會產生可被引用的 receipt，但沒有真實資產流動。

// 06-STEP · ROUTED PAYMENT

AgentPay 不是「卡 + 一次性授權」 — 它是 一個有限狀態機。每一步都驗證上一步的產出，沒有人工確認的步驟會停在 [HOLD]；沙盒只展示控制與收據結構，不宣稱已完成鏈上結算。

當前為 沙盒協議，沒有真實資產流動。主網與正式商用時間尚未公告。
