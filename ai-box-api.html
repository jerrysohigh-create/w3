DEVELOPER PREVIEW · DEVICE ACCESS REQUIRED

MAGNE.AI BOX Developer API Guide

Developer preview v0.1 · Content updated 2026-11-07

This guide covers local inference, knowledge retrieval and model management on provisioned MAGNE.AI BOX preview devices. ROC is the software/service naming used in the current handoff materials. This guide does not establish MAG1 compatibility.

Use a preview device with the documented interfaces and HTTPS administration enabled. Check the delivery record and GET /v1/version for the supported build. Requests use OpenAI-style structures; full API or arbitrary agent-tool compatibility is not implied.

Connection prerequisites

Obtain a provisioned device, a USB data cable, ADB, the supplied administration trust certificate, administrator credentials and an application token through your device delivery process. Initialization and administrator recovery are separate maintenance procedures.

Examples use POSIX shell syntax. On Windows, use a configured WSL or Git Bash environment.

SH
adb devices -l
adb -s DEVICE_SERIAL forward --no-rebind tcp:8080 tcp:8080
adb -s DEVICE_SERIAL forward --no-rebind tcp:18081 tcp:18081

Replace DEVICE_SERIAL with your actual device identifier. If a port is occupied, inspect adb forward --list before changing mappings.

Business base URL: http://127.0.0.1:8080/v1. Administration base URL: https://127.0.0.1:18081/admin/api. Business HTTP is limited to loopback and controlled USB forwarding. Connecting Wi-Fi does not expose a LAN API. Access from other hosts requires a controlled connection configured by the deployment operator.

Do not expose ADB or these ports directly to the Internet. This documentation website does not need your device secrets. Do not bypass certificate validation with -k. Older HTTP administration builds require their matching delivery instructions.

Discover a model and send a request

Supply ROC_API_TOKEN through your local secure environment. This is an application token, not an administrator session. Never embed real credentials in website code, public examples or logs.

SH
BASE=http://127.0.0.1:8080/v1
curl -sS "$BASE/version" -H "Authorization: Bearer $ROC_API_TOKEN"
curl -sS "$BASE/models" -H "Authorization: Bearer $ROC_API_TOKEN"
curl -sS "$BASE/models/local%2Fqwen35-35b/health" \
  -H "Authorization: Bearer $ROC_API_TOKEN"
curl -sS "$BASE/chat/completions" \
  -H "Authorization: Bearer $ROC_API_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"model":"local/qwen35-35b","messages":[{"role":"user","content":"What is 19 + 23? Reply only the integer."}],"temperature":0,"max_tokens":32,"stream":false}'

Select the public model ID returned by your device. local/qwen35-35b is a delivery example and a service alias, not proof of an exact model revision or quantization. URL-encode slashes in path IDs. Wait for model_ready=true; an unloaded model must first be loaded by an administrator.

Read the answer from choices[0].message.content. Include the required messages history for multi-turn conversations. For streaming chat, use stream:true and curl -N; read SSE until [DONE]. A disconnected stream is not a successful completion.

Embeddings and reranking

SH
curl -sS "$BASE/embeddings" \
  -H "Authorization: Bearer $ROC_API_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"model":"npu/embedding","input":"Document text"}'
curl -sS "$BASE/rerank" \
  -H "Authorization: Bearer $ROC_API_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"query":"network","documents":["network setup","weather"],"top_n":2}'

The documented embedding configuration returns 1,024 dimensions in data[0].embedding. Reranking returns document indexes and relevance scores in results. Check the administration model catalog for npu/embedding and npu/rerank; their status is not available through /models/{id}/health. Startup readiness may temporarily cause HTTP 503.

Save the following as rag.json, replacing the model and vector-store IDs:

JSON
{
  "model": "local/qwen35-35b",
  "instructions": "Answer briefly and cite the source.",
  "input": [{"role":"user","content":"What is the verification keyword?"}],
  "tools": [{"type":"file_search","vector_store_ids":["YOUR_VECTOR_STORE_ID"]}],
  "max_output_tokens": 128,
  "stream": true
}
SH
curl -sS -N "$BASE/responses" \
  -H "Authorization: Bearer $ROC_API_TOKEN" \
  -H 'Content-Type: application/json' --data-binary @rag.json

Only response.completed indicates full success. For response.failed, inspect response.last_error. Treat response.incomplete and a connection closing before a terminal event as incomplete. Retain X-Request-ID; do not blindly retry after partial output.

Display returned file citations with answers. OCR is part of document ingestion. Supported formats, sizes, page counts and complex layouts depend on the delivered configuration and testing. Successful ingestion does not guarantee correct extraction of every document.

Delete a store with DELETE /v1/vector_stores/{id} and a file with DELETE /v1/files/{file_id} after checking ownership and purpose.

Administrator authentication and application tokens

Log in through POST /admin/api/login with JSON username and password. Use the returned session as the Bearer credential for management requests and validate HTTPS against the delivered certificate. Log out through POST /admin/api/logout.

Applications use separate tokens. Administrators issue, rotate and revoke them through the delivered management interface or approved tooling. Grant only required scopes: inference, embeddings, rerank and rag. Ordinary application-token plaintext is returned at issuance or rotation; rotation invalidates the old token. Replace lost tokens rather than trying to recover them. Device handoff and maintenance credentials follow a separate process.

Load or switch models

Supply a valid ADMIN_SESSION through your secure local environment. Replace TARGET_ID and COPY_REVISION with values from the current administration catalog. Management IDs may differ from business model IDs.

SH
ADMIN=https://127.0.0.1:18081/admin/api
curl -sS --cacert provider-admin-trust.pem "$ADMIN/models" \
  -H "Authorization: Bearer $ADMIN_SESSION"
curl -sS -i --cacert provider-admin-trust.pem "$ADMIN/models/switch" \
  -H "Authorization: Bearer $ADMIN_SESSION" \
  -H 'Content-Type: application/json' \
  -d '{"target":{"id":"TARGET_ID","revision":"COPY_REVISION"}}'
curl -sS --cacert provider-admin-trust.pem "$ADMIN/models/operations/OPERATION_ID" \
  -H "Authorization: Bearer $ADMIN_SESSION"

Use switch when another model is resident and load when none is resident. HTTP 202 means accepted, not completed. Save operation_id and poll the same operation until succeeded, failed or cancelled. Pause business requests during a switch. Resume after the operation succeeds, the target model is ready and a short inference request succeeds. Cold loading may take minutes.

Read the boot policy with GET /admin/api/models/policy. PUT replaces the full policy with a version lock; preserve other fields and re-read on HTTP 409. Saving a boot policy does not switch the current resident model.

Health and troubleshooting

Management routes include GET /admin/api/status, /health, /system/health, /device/thermal, /device/thermal/history and /audit/export. All require an administrator session and HTTPS certificate validation.

HTTPAction
400Check request fields, model and parameters
401/403Check token, session and scope; log in again or rotate as appropriate
404Check route, encoded model ID and feature availability
429Reduce concurrency or wait for login lockout to expire
503Check model readiness; retain error code and request ID

Report the time and timezone, version, model ID, request type, HTTP status and X-Request-ID. Remove credentials and sensitive business content before sharing logs.

Re-establish forwarding after USB reconnection. Remove it after use:

SH
adb -s DEVICE_SERIAL forward --remove tcp:18081
adb -s DEVICE_SERIAL forward --remove tcp:8080

Recorded validation and revision

The partner's 2026-11-03 first-board materials report validation of 35B chat, non-streaming and streaming file retrieval, OCR ingestion, VectorDB retrieval, embeddings and reranking. They record weight checks for 4B/8B, not fresh inference validation. ASR, TTS, image generation and web search had not completed that first-board acceptance. This does not establish validation across all firmware, documents or third-party agents.
